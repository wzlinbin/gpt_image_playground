# 项目上下文摘要（界面入口精简与品牌改名）

生成时间：2026-07-27 13:18:00 +08:00

## 1. 目标与范围

- 删除设置侧栏“关于”菜单及其不可达内容。
- 删除页头桌面端和移动端的“画廊/Agent”切换按钮，不删除 Agent 业务模块或已有数据。
- 删除操作指南底部作者文案与 GitHub 快捷链接。
- 将运行时、浏览器标签和 PWA 名称从“GPT Image Playground”统一为“生图中心”，标题不再跳转外部仓库。
- 保留 API Key 首次弹窗、配置锁定、默认流式/Base64 和 iframe 嵌入改造。

## 2. 三个现有实现分析

- `src/components/Header.tsx`：页头标题、版本快捷链接和桌面/移动模式切换均在同一组件中；删除 JSX 后应同步删除滚动方向状态和版本检查依赖。
- `src/components/SettingsModal.tsx`：`SettingsTab` 联合类型、侧栏按钮和内容条件分支形成完整导航契约；删除菜单时应同步删除三处，避免死代码和无效类型。
- `src/components/HelpModal.tsx`：正文与底部作者链接是两个独立布局区；删除底部区域后正文无需保留 `mb-6`。
- 补充模式：`index.html` 与 `public/manifest.webmanifest` 分别控制浏览器标签、iOS/PWA 安装名称，需与页头同步。

## 3. 项目约定与复用

- React 函数组件与 hooks；2 空格、单引号、无分号。
- 沿用现有 Tailwind 布局，不新增组件、依赖、脚本或状态。
- 复用 `.claude/verify-api-key-prompt.mjs` 做真实 DOM 冒烟验证，补充品牌、按钮、菜单和外链断言。

## 4. 测试策略

- 静态检索确认运行时代码不再包含旧品牌、关于入口和 GitHub 作者链接。
- 浏览器冒烟覆盖页头、操作指南、设置侧栏及移动端边界。
- 执行 `npm run build`、`npm test`、`git diff --check`。

## 5. 依赖、集成点与风险

- 内部依赖：Zustand `appMode` 仍用于既有页面渲染和 Agent 内部动作；本次只删除切换控件，不修改持久化协议。
- 元数据：浏览器标题、Apple Web App 名称和 manifest 名称同步更新。
- 风险：移除移动切换栏后必须同时移除隐形占位，否则页头下方会保留空白。
- 性能：删除代码和外部版本检查调用，运行时开销只会下降。
- 工具说明：当前会话未提供仓库指定的 `sequential-thinking`、`shrimp-task-manager`、`desktop-commander`、Context7 与 GitHub 搜索工具；本任务为仓库内既有 UI 删除，无外部库用法变化，使用结构化分析、PowerShell/rg 和本地自动化验证补偿。
