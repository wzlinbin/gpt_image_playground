# 项目上下文摘要（扩大文字输入框并删除搜索筛选栏）

生成时间：2026-07-27 13:38:00 +08:00

## 1. 目标与范围

- 扩大底部提示词输入栏的桌面宽度和文字编辑区高度。
- 删除首页收藏、状态筛选和提示词搜索整行。
- 保留任务网格、收藏标记与批量操作等其他业务能力。

## 2. 三个现有实现分析

- `src/components/InputBar.tsx`：外层 `max-w-4xl` 控制整体宽度；编辑区 `min-h-[42px]`、`prevHeightRef` 和 `adjustTextareaHeight` 的 `minH` 共同控制高度，三处必须同步修改。
- `src/App.tsx`：`SearchBar` 与收藏夹概览条件在首页唯一挂载点；删除后应直接渲染 `TaskGrid`，同时移除无用 store 订阅与导入。
- `src/components/SearchBar.tsx`：图二整行是一个独立组件，包含收藏、状态筛选和文本搜索；无需修改组件内部或复制其逻辑。
- 补充响应式模式：项目主内容与页头使用 `max-w-7xl`，输入栏使用 `max-w-6xl` 可明显增宽并保留桌面边距；移动端仍受 `w-full` 和横向 padding 保护。

## 3. 实现与测试约定

- 继续使用现有 Tailwind 响应式类，不新增 CSS、依赖或脚本。
- 编辑区最小高度统一为 64px，保证初始渲染和动态高度计算一致。
- 扩展 `.claude/verify-api-key-prompt.mjs`，通过实际边界框断言桌面输入宽度大于 1000px、高度不小于 64px，且搜索行不存在；移动端断言不溢出。
- 执行生产构建、完整 Vitest、浏览器截图、Wrangler dry-run 和 `git diff --check`。

## 4. 风险与边界

- `searchQuery`、`filterStatus` 和 `filterFavorite` 默认分别为空、`all` 和 `false`，不会因删除入口而默认隐藏任务。
- 首页不再进入收藏夹概览，但任务自身收藏标记、收藏选择弹窗和数据仍保留。
- 输入栏变高后由既有 `ResizeObserver` 更新页面底部避让距离，无需新增固定 padding 计算。
- 当前会话仍未提供仓库指定的专用分析工具，使用结构化分析、仓库内三个实现对比和本地自动化验证补偿。
